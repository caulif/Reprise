# 文档工作指令

先读任务相关的当前文档；入口见[导航](./README.md)。内容归属与维护流程见[贡献指南](./CONTRIBUTING.md#文档维护)，目录及受控边界见[结构约定](./documentation-structure.md)。

- 当前事实、未完成目标、历史理由分开；代码与文档冲突先核对证据，不自动认定代码错误。
- 不复制字段、枚举或 prompt；改生成区的源后重新生成。
- 仓库引用使用相对 Markdown 链接。移动文件同时修入站链接、生成目标和门禁配置。
- 一次性审查写入 Git 忽略的 `.local/`；受控文档不能依赖本机证据。
- 只改文档运行 `npm run verify:docs`；涉及脚本则补对应验证。不要用放宽门禁代替修正文档。
