# 行为准则

本准则适用于项目 Issue、PR 与其他项目协作讨论。欢迎不同经验的贡献者；讨论应针对代码、文档、方案和可复核证据，尊重他人时间与不同意见。

不可接受的行为包括骚扰、歧视、人身攻击、威胁、公开他人隐私或凭据、在公开讨论中泄露未协调披露的漏洞细节，以及强迫未同意的人承担付费 Runtime 调用。

维护者 `@caulif` 根据行为与影响处理报告，可以提醒、警告、关闭相关讨论或贡献，或屏蔽持续违规者。处理应围绕具体事实，而不是技术意见是否与维护者一致；项目不承诺独立仲裁机构或固定处理时限。

## 报告行为问题

本项目**没有**为行为问题提供 GitHub 私信或私密工单。[GitHub Discussions](https://github.com/caulif/Reprise/discussions) 与 Issue **均为公开页面**，Discussions 不支持私信。

**最短路径：** 在 Discussions 发一篇**仅含最少文字**的公开帖，例如「需要就行为问题联系维护者」，**不要**写入当事人身份、聊天记录、截图、链接或任何可识别细节。维护者看到后会通过其认为合适的方式私下跟进。开 Issue 时勿用 Bug/Feature 表单填写行为细节；可在 Issue 列表页使用「行为问题（公开请求联系）」链接。

安全漏洞请使用[安全政策](./SECURITY.md)的**私有**报告入口，不要用本渠道提交漏洞或凭据。普通使用问题见[中文 README](../README.zh-CN.md#支持与贡献)。
