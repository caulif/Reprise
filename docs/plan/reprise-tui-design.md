# Reprise TUI 阅读与交互规划

本文是目标设计，与[整体重构规划](./reprise-architecture-redesign.md)配套，不覆盖当前产品规范。阅读与折叠合同见[公开活动时间线](../decisions/accepted/2026-09-08-public-activity-timeline.md)。

## 信息与页面

一个实验一条连续记录：恢复、模拟用户与候选协作、执行结束、可选对照及其结果顺序追加。历史打开默认定位最后结果，仍能向上阅读全过程。首页只提供新实验、历史实验与设置；来源会话选择展示产品、项目、任务、时间与起点预览。内部模型配置与候选产品模型分开，候选目录来自插件。配置失败明确原因，不显示密钥。

恢复显示调查目标、可见发现、最新操作和缺口；证据不足解释后停止，不提供强行继续。恢复可用后选择候选产品与模型并开始。运行结束区分模拟用户的任务判断、技术终止及清理结果；直接给产物路径和可选对照入口。对照在同一记录追加，每次 attempt 有独立边界。可用场景允许以后创建新候选运行，不能将其表现为恢复执行旧进程。

默认单列，模拟用户与候选按时间交替。模拟用户的可见进度文字保留，调查工具折叠在实际投递消息之前；消息卡区分待投递、已接受、拒绝或未知。随后追加候选的公开过程，保留模拟用户内容。并发活动按记录顺序排列并明确来源，不捏造严格串行执行。顶部只放任务、阶段、产品模型、状态与耗时，轮次不用于恢复阶段。不显示推测百分比。

## 键盘入口与层级选择

首页沿用现有项目的斜杠命令习惯：常用入口为 /intake、/history、/config，帮助收在 /help。输入 / 打开与筛选建议，↑ ↓ 移动，Tab 补全，Enter 执行。首页输入只接收应用命令，不作为 Agent 对话输入。实验时间线内 / 表示当前记录搜索，界面底部提示当前语义。

来源选择分为产品、项目、会话、起点核对四层。列表 ↑ ↓ 选择、Enter 确认、Esc 返回上一层；会话列表输入关键词过滤，空结果不得确认。会话 Enter 只打开核对，核对 Enter 才开始准备。返回保留选项与筛选位置是实施验收项，不重新扫描无变化的列表。

选择来源产品后使用独立的项目页。宽终端采用左右布局：左侧可滚动项目列表，支持按项目名或路径筛选；右侧固定展示选中项详情，上下键切换时更新内容，Enter 进入会话。大量项目以分页或虚拟列表加载，键盘选中项保持可见；空匹配禁止确认。窄终端回退为列表在上、详情在下，不缩成两列截断。项目页明确当前产品、已发现项目及会话数、排序依据；每行展示项目名、会话数、最近活动，选中项下方展示完整项目路径和最近任务。仅扫描所选产品的历史，不因查看而启动 Runtime。进入项目后，会话页展示可筛选任务列表与选中会话摘要，Enter 进入起点核对。空列表区分没有历史、筛选无匹配和读取失败，不能用空列表掩盖错误。预览导航提供项目页与会话页的直接入口，业务流程仍逐层进入。

内部模型页沿用字段列表与单字段编辑模式：↑ ↓ 选字段，Enter 编辑；编辑态 Enter 应用到草稿，Esc 撤销；Ctrl+S 校验并保存，失败保留草稿与明确原因。存在未保存修改时退出需要明确保存或放弃，不静默丢弃。模型目录可列举时采用可筛选列表，自定义模型允许文字输入。内部模型与候选模型目录分开。候选产品、候选模型和开始确认同样采用分层键盘选择。

终端底部使用按键提示，不画网页按钮工具栏。时间线 ↑ ↓ 和翻页键用于阅读，Tab/Shift+Tab 聚焦可展开条目，Enter 展开或收起；v 切换阅读／选择模式，End 回到最新。搜索态 Enter/Shift+Enter 导航匹配，Esc 关闭。执行结束 c 发起对照，Esc 返回首页；运行中 Esc 不取消或离开执行所有者，Ctrl+C 才请求取消。网页外侧阶段导航与演示完成操作是原型控制，不属于目标 TUI。

结果直接显示可复制的本地路径。支持时使用 OSC 8 file URI 链接，目标为已记录、实际存在的本机产物；Windows 通常 Ctrl+点击，macOS 通常 Cmd+点击，Linux 通常 Ctrl+点击，具体遵循终端配置。不把修饰键手势称为操作系统统一保证。路径编码处理空格、中文及盘符，链接不拼接 shell 命令；不支持链接时保留完整路径以便复制。示例路径不创建文件，HTML 点击只解释其用途，不假装打开成功。

## 内容展开

可见进度说明、发现和结论默认展开；公开长篇推理摘要独立折叠。禁止伪造隐藏推理或把工具次数称为思考。模型没有可见文字时显示真实操作或等待状态。工具运行中只突出最新活动，并发时附其他活动数；完成组可展开每次操作，失败与影响结果的限制始终可见。命令、有限输出和相关文件原地展开，完整输出可按需继续；完整 diff、长文件交给编辑器。原始事件在深层记录入口，不是首页导航项。

折叠仅改变视图，不丢弃记录；错误、投递和结论不得因工具合并被吞掉。未知插件活动展示通用标题与来源，只有插件公开信息才进入视图。敏感内容与终端控制字符在展示边界处理，文本不作为命令执行。

## 滚动、复制与搜索

滚轮和方向键、PageUp/PageDown、Home/End 均可浏览。默认跟随末尾，向上阅读时暂停，显示新活动提示；End 或回到最新恢复跟随。正在选择文字、展开详情或搜索时不得抢动阅读位置。以条目身份和条目内偏移保持锚点，缩放、追加、折叠、历史分页不跳页。用户主动滚回底部可恢复跟随，选择模式与搜索模式优先暂停。

用户偏好鼠标拖选任意文字。终端鼠标报告会与原生拖选冲突，不承诺所有终端同时支持无修饰拖选及应用滚轮。提供显式阅读／选择模式：停止跟随和当前视图重绘，关闭鼠标报告，保留事件接收与持久化；返回时提示累计新活动。普通模式只启用所需鼠标报告，不抢占无用途的移动事件。按宿主验证 Shift 拖选及原生复制；不支持的宿主可常驻选择模式并用键盘滚动。进入选择模式不保证替代屏幕缓冲拥有原生历史，需验证退出与选区行为。HTML 的浏览器选区只演示阅读体验，不证明真实终端兼容。

按 / 搜索当前实验已记录的可见消息及活动标题，包含已折叠和分页未加载记录，不搜索默认隐藏的长推理、工具长输出或原始事件。命中按记录顺序导航，自动展开所在组；Esc 退出并保留当前位置，不自动跟随。搜索匹配源文本并高亮展示，不能让旧高亮进入后续索引。输入框、IME 组合输入与文字选择期间不截获普通快捷键。

## 操作与所有权

运行中只查看与取消，无聊天输入框，无原生产品第二窗口。Ctrl+C 请求取消，展示取消中，只有所有者确认终态才显示已取消；另一终端 cancel 的结果经同一记录显示。强制退出、中断、不可达、清理失败分别说明，不视为成功或自动续跑。浏览记录不是关闭执行所有者；只读观察窗口退出不得取消其他进程的实验。所有业务操作复用 CLI 的应用服务，TUI 不持有实验状态机。

Product Pack 将公开消息、工具、结果、文件变化和状态规范化；宿主统一布局与措辞，不嵌入产品原生 ANSI 画面。保留来源、顺序和稳定活动身份以支持流式更新与去重。正常产品扩展不要求新增 TUI 分支。协议决策沿用[重构决策](../decisions/proposed/2026-09-07-reprise-session-harness-workflow.md)。

## 视觉与验收

深浅主题保持同一信息层次，常规正文低彩度，一种强调色，成功和异常同时使用文字与符号。窄屏自然换行，路径允许横向查看或完整展开，不把长文字变成一整行截断。固定底栏仅显示当前可用操作；键盘焦点可见，不依赖鼠标或颜色理解状态。

实施验收覆盖：完整与分步路径在同一实验下可读；恢复不足停止；投递未知与失败可见；插件缺少过程时诚实降级；长时间运行滚动不跳；搜索找到折叠及分页记录；选区不因追加失效；取消请求与终态区分；重开历史不执行副作用。Windows Terminal/PowerShell、macOS Terminal/Bash、Linux 选定终端/Bash 分别验证滚轮、拖选复制、中文、IME、缩放、键盘、退出恢复。未验证宿主不标为支持。

预览的页面切换、搜索、详情展开、新活动、阅读模式和取消均为本地演示。真实进程取消、终端输入协议、磁盘分页与产品适配需实施阶段验证。
