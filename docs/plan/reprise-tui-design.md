# Reprise TUI 阅读与交互规划

状态：已确认的目标交互设计；当前实现界面仍以 `product/tui.md` 为准。

## 信息与页面

TUI 是一条单窗口、键盘优先的本地工作流：配置内部模型、选择会话、选择候选 coding agent 与模型、启动、查看结果、选择是否对照。它不启动 CLI 子进程，不向候选 Runtime 提供人工输入，也不承担实验状态。

页面只保留：

- 配置：显示共享内部模型配置与认证状态，秘密全遮罩；
- 会话选择：按来源 Product Pack、项目和会话分层浏览；
- 候选选择：来源会话与候选 Product Pack 分开，候选模型来自候选 Pack；
- 预检与确认：说明本机条件、费用准入和隔离目录；
- 运行：只读时间线、最近活动和取消；
- 结果与历史：任务判断、终止、清理、产物路径和可选对照入口；
- 对照：明确由用户启动，显示独立 attempt 的活动和报告入口。

恢复证据不足时留在结果/诊断路径，展示缺口与已保存调查；不能进入候选选择。程序重开后可在历史页查看全过程，不能 reattach 或自动续跑。

## 活动呈现

主时间线只投影已公开事实，并标明来源：Harness、Recovery/Controller/Comparison、Target。模型隐藏 reasoning 不显示也不伪造。

一个实验一条单列连续记录，依次追加恢复、模拟用户与候选协作、执行结果和可选对照。历史打开定位最后结果，前面的全过程仍可滚动阅读。模拟用户的公开进度、发现与决定保留；其调查工具折叠在实际投递消息之前。投递消息突出并标注接受、拒绝或未知，接着追加候选公开过程，不清空模拟用户文字、不切换双窗口。

文字进度、发现和结论默认显示；长篇公开推理摘要单独折叠。最新工具活动占一行，较早操作合并为可展开组；并发时附其他活动数。命令、有限输出和相关文件原地展开，完整 diff、长文件交给编辑器；原始事件放在更深的记录入口。折叠不删除记录，错误、停止原因和影响结果的限制不隐藏。无公开文字时显示真实活动或等待，不把工具次数包装成思考，不额外调用模型编造过程。

顶部只保留任务、阶段、候选产品模型、状态与耗时，不展示推测百分比，恢复阶段不显示候选轮次。用量只显示确实记录的值。插件把公开消息、工具和执行事实转成通用活动；宿主统一布局，不嵌入原生 ANSI 画面或增加产品专属 UI 分支。

运行页允许阅读、搜索、展开与取消，不提供消息输入、换模型或人工接管。Ctrl+C 表示请求取消，收尾完成后才显示已取消；取消、进程中断与清理失败分别说明。页面底部显示当前可用按键而非按钮工具栏；退出只读观察页不取消其他所有者的实验。delivery 状态只能来自 Runtime 协议。

## 选择、滚动与搜索

首页用 /intake、/history、/config 和 /help 作为少量常用入口；/ 打开命令建议，↑ ↓ 选择、Tab 补全、Enter 执行。首页只接收应用命令。列表 ↑ ↓ 选择、Enter 确认、Esc 返回上层，保留筛选与选择位置。配置页是字段列表，Enter 编辑，编辑态 Enter 应用、Esc 撤销，Ctrl+S 校验保存；有未保存草稿时明确保存或放弃。候选产品与模型分层选择，恢复可用后才进入候选选择。

来源流程为产品 → 项目 → 会话 → 起点核对。03a 产品下项目页在宽终端采用左右布局：左侧可滚动、可按项目名或路径筛选的列表；右侧固定显示选中项目完整路径、会话数、最近活动与任务。上下键更新右侧，Enter 进入会话；窄终端上下排列，不挤成两列截断。多项目分页或虚拟加载，选中项保持可见；空匹配不可确认。03b 展示任务、时间与选中会话摘要，Enter 先核对起点，再确认准备。读取失败、没有历史与筛选无匹配分别说明。

滚轮、方向键、PageUp/PageDown、Home/End 浏览记录。默认跟随最新，向上阅读后暂停，新活动只增加提示；End 或回到底部恢复跟随。搜索、展开详情、缩放及追加记录保持条目阅读锚点。Tab/Shift+Tab 聚焦详情，Enter 展开或收起。输入框和 IME 组合输入不被普通快捷键截获。

用户优先鼠标拖选复制。终端鼠标报告可能与原生选区冲突，不能承诺所有宿主无修饰拖选与应用滚轮同时可用。v 进入阅读／选择模式：关闭鼠标报告、暂停跟随与当前视图重绘，后台仍接收和持久化事件；返回提示新活动。Shift 拖选等手势按宿主验证，无鼠标能力时保留完整键盘路径。HTML 浏览器选区不是终端兼容证据。

实验时间线内 / 搜索该实验已记录的可见消息与活动标题，包含折叠和分页未加载记录；长推理、工具长输出与原始事件不纳入默认搜索。Enter/Shift+Enter 导航，命中自动展开所在组，Esc 关闭并保留当前位置。首页 / 是命令入口，会话列表输入用于筛选，各自提示当前语义。

执行结束在原时间线追加任务判断、终止、清理结果与产物路径；c 发起对照，也可直接查看路径或以后从历史发起。实际存在的本地产物支持 OSC 8 file URI，Windows 通常 Ctrl+点击、macOS 通常 Cmd+点击、Linux 通常 Ctrl+点击，以终端配置为准。不支持链接时保留可复制完整路径。处理空格、中文和盘符编码，不拼 shell 命令，不链接未验证的任意目标。

会话列表的摘要只是展示窗口，不能以摘要不完整提前断言不可恢复。来源身份使用 `productId + sessionId`，歧义时使用 `sourcePath`，不以标题或列表序号作为操作标识。

## 验收

- 首次路径无需理解内部模块名；
- 用户可区分内部模型与候选 Runtime 模型；
- 运行中没有追加指令、暂停或换模型入口；
- 进度、取消、最终结果、清理状态和产物路径始终可见；
- 对照默认为未运行，能从结果和本机历史独立启动；
- 历史过程来自持久化事件，重开后可读；
- 宽屏和窄屏均能完成相同工作流；
- TUI 不伪造 reasoning，也不把模型自述包装成已验证事实。

键盘闭环覆盖命令补全、配置应用/撤销、逐层选择/返回、结果与独立对照；03a 用大量项目验证滚动与筛选，空匹配不能进入；持续追加时向上阅读与选区不跳，搜索找到折叠及分页记录。Windows/macOS/Linux 分别验证中文、IME、缩放、滚轮、拖选、链接、终端退出恢复；记录终端及版本，不能用网页预览替代。

本机 HTML 是非权威交互草图，外侧预览导航和模拟完成按钮不是 TUI 操作。完整规划以本文件为准；公开检出无需本机 HTML 才能理解或实现设计。
