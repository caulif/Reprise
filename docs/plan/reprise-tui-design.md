# Reprise TUI 阅读与交互规划

状态：已确认的目标交互设计；当前实现界面仍以 `product/tui.md` 为准。

## 信息与页面

TUI 是一条单窗口、键盘优先的本地工作流：配置内部模型、选择会话、选择候选 coding agent 与模型、启动、查看结果、选择是否对照。它不启动 CLI 子进程，不向候选 Runtime 提供人工输入，也不承担实验状态。

页面只保留：

- 配置：显示共享内部模型配置与认证状态，秘密全遮罩；
- 会话选择：按来源 Product Pack、项目和会话分层浏览；
- 候选选择：来源会话与候选 Product Pack 分开，候选模型来自候选 Pack；
- 预检与确认：说明本机条件、费用准入和隔离目录；
- 运行：只读时间线、最近活动和取消；
- 结果与历史：任务判断、终止、清理、产物路径和可选对照入口；
- 对照：明确由用户启动，显示独立 attempt 的活动和报告入口。

恢复证据不足时留在结果/诊断路径，展示缺口与已保存调查；不能进入候选选择。程序重开后可在历史页查看全过程，不能 reattach 或自动续跑。

## 活动呈现

主时间线只投影已公开事实，并标明来源：Harness、Recovery/Controller/Comparison、Target。模型隐藏 reasoning 不显示也不伪造。

默认显示阶段、候选、实际 resolved model、最近可见消息、工具活动摘要、投递确认、取消/错误和有限用量。完整工具参数、输出、原始事件、artifact、diff 和报告通过详情按需打开。窄终端保持同样的操作，只将双栏变成焦点切换或独立页面。

运行页是只读观看面：只提供 `Ctrl+C` 取消与 `?` 帮助。页面底部只显示当前实际响应的按键。候选的每条实际输入必须独立显示，并与 Controller 可见过程区分；delivery 状态只能来自 Runtime 协议。

## 选择、滚动与搜索

斜杠入口用于跳转页面和搜索，不把每项操作做成按钮工具栏。列表支持方向键、Enter、Esc、刷新和分页；滚轮和拖选阅读在所有长内容区域可用。搜索匹配可见消息、活动标题和历史元数据，不扫描或泄露秘密。

会话列表的摘要只是展示窗口，不能以摘要不完整提前断言不可恢复。来源身份使用 `productId + sessionId`，歧义时使用 `sourcePath`，不以标题或列表序号作为操作标识。

## 验收

- 首次路径无需理解内部模块名；
- 用户可区分内部模型与候选 Runtime 模型；
- 运行中没有追加指令、暂停或换模型入口；
- 进度、取消、最终结果、清理状态和产物路径始终可见；
- 对照默认为未运行，能从结果和本机历史独立启动；
- 历史过程来自持久化事件，重开后可读；
- 宽屏和窄屏均能完成相同工作流；
- TUI 不伪造 reasoning，也不把模型自述包装成已验证事实。
