# 确认页只留开跑决策

状态：计划。设计稿见 [confirm-page-simplify.html](./confirm-page-simplify.html)。落地时改 [`src/tui/pages/run.ts`](../../src/tui/pages/run.ts) 的 `renderConfirmation`、[tui.md](../product/tui.md) 确认段，并重跑 `npm run audit:tui`。本文不覆盖当前产品规范。

选产品、选模型见 [candidate-model-picker.md](./candidate-model-picker.md)。确认页是唯一会启动进程、产生费用的门。它回答的是「现在按 Enter 会发生什么」，不是再讲一遍恢复过程。

## 1. 当前问题

`renderConfirmation` 把预检、恢复诊断和免责声明摊在同一块面板里。操作者已经看过恢复终态、已经选过产品和模型，确认页仍重复：

| 现在画的 | 为什么不该在确认页 |
|---|---|
| 变更路径条数、跳过路径、未决长句 | 恢复页已经给过终态；未决原文是诊断，不是开跑选择 |
| 最大请求数（候选 / 控制器 / 对照） | 策略默认值，本页不能改 |
| 网络 / 计费「是 / 取决于服务商」 | 与费用警告重复，且不是可操作事实 |
| 隔离副本绝对路径 | 顶栏和结果页能找到；确认时不需要念路径 |
| 四条 √/⚠ 长句 | 同一件事写四遍：花钱、不改原目录、从副本跑、副本不是脱敏 |

面板外还常留下「已恢复。先选候选产品…」这类流程提示。确认页已经过了那两步，不应再教怎么走流程。

## 2. 确认页只回答四件事

能开跑时，面板里只保留：

1. **问句**：要不要启动隔离候选。
2. **谁跑**：候选产品 + 已选模型（`displayName` / `value`，解析名与显示名不同时才附一行小字）。
3. **对照什么**：恢复终态一词（已恢复 / 部分恢复）。来源产品与候选产品不同时，加一行「来源 X → 候选 Y」和一句「同一任务，另一套 Runtime」。
4. **按 Enter 的后果**：一条费用警告；一条「原目录不变，候选读的是副本」。

不能开跑时，标题改成无法启动，只留**一条**原因（缺凭据，或恢复没有可运行工作区）。不堆诊断代码、不堆路径列表。

题目已经在工作台顶栏。确认页不再复制任务句、不再写变更条数、不再写 max turns、不再写源目录绝对路径。

## 3. 能开跑的版式

```text
第 3 / 3 步 — 确认运行      √──√──●

┌ 启动隔离的 Claude Code 候选？ ─────────┐
│                                        │
│  候选     Claude Code  ·  sonnet       │
│  恢复     部分恢复                     │
│  来源     Codex                        │  ← 仅跨产品
│                                        │
│  ⚠  Enter 会启动 Claude Code，可能产生费用。
│  ✓  原目录不变。候选只读写隔离副本。   │
└────────────────────────────────────────┘
```

同产品时不写「来源」行，也不写跨产品那句。部分恢复与已恢复都只用一词；细节回恢复页。

底栏保持：`[Enter] 启动隔离候选`  `[b] 改模型`  `[Esc] 封面`。

## 4. 不能开跑

标题：无法启动隔离候选。正文只留候选一行 + 一条红色原因。Enter 提示改为不可用。`b` 仍回选模型（凭据问题则去 `/config`，文案写在原因里）。

## 5. 事实放在哪

| 事实 | 归宿 |
|---|---|
| 恢复终态、变更条数、未决、失败原因 | 恢复页 / 核对页 |
| 文件数、源目录大小、Runtime 可执行文件 | 预检页（若仍保留）或 overlay，不进确认 |
| `RunPolicy` 上限 | 不在确认页展示；要改策略另开设置，不塞进开跑门 |
| 隔离工作区路径 | 开跑后的运行/结果页 |
| 候选产品、模型 | 选产品页、选模型页写入；确认页只复述已选项 |

`confirmCanStart` 条件不变：缺 Harness 凭据、观察性对照、恢复失败、有恢复结果但没有 `CandidateSpec` 时禁止启动。本计划只改展示，不放宽启动门。

## 6. 文案约束

- 中英都写短句。费用那条必须点名候选产品。
- 禁止在确认页出现 `recoveryReady` 这类「先选产品再选模型」提示。
- 禁止把 `provider_validation_failed` 等代码当正文。
- 跨产品一句沿用现有含义：对照同一恢复任务，不是把历史会话改写成另一产品。
