# 鹈鹕骑自行车：一次真实交付对照

[English](pelican.md) · [返回 Reprise](../../README.zh-CN.md)

原始需求是：“不用skills，创建一个HTML，内容是SVG绘制一个鹈鹕骑自行车的2D动画”。

Reprise 从记录中的文件编辑恢复历史 HTML，再与保留的候选工作区交付进行比较。这个案例说明了直接查看交付物的价值：候选版改变了骑行机制，但也失去了一个实用的播放控制。

![相同视口下的历史与候选鹈鹕 HTML 交付对照，左右分别标注来源](../assets/pelican/comparison.png)

## 查看交付物

[查看短动画](../assets/pelican/comparison.gif)（3 秒，约 3 MB）。这是已有 HTML 交付在 Chromium 中播放的录屏，**不是重新运行 Reprise 全流程的录屏**。含运动内容，如不适请使用上方静态图。短片为展示而循环播放，不表示原动画能在剪辑端点无缝衔接。

克隆仓库后，可在本机打开 [showcase.html](../assets/pelican/showcase.html) 查看双方成果，也可直接查看 [historical.html](../assets/pelican/historical.html) 和 [candidate.html](../assets/pelican/candidate.html)。GitHub 文件页显示 HTML 源码，不直接运行。两个原始 HTML 按字节复制，仅外层对照页与展示媒体为本次新增。它们均为自包含页面，预览不需要模型、登录、服务器或外部资源。

## 具体差异

以下观察在 2026-10-19 通过源码与新一轮本地 Chromium 播放独立核对。这是编辑整理的展示摘要，不是原始生成报告。

| 细节 | 历史交付 | 候选交付 |
| --- | --- | --- |
| 车轮 | 两组辐条共用一个旋转组，旋转中心在双轮之间；轮圈不动，辐条会偏离各自轮心。 | 每个车轮以自己的轮心为旋转原点。 |
| 踩踏 | 脚留在骑手组内，曲柄单独旋转。 | 脚本从同一个角度更新曲柄、腿和脚，改善协调关系；不代表脚掌接触完全精确或符合真实自行车运动学。 |
| 控制与背景 | 点击、Enter 或空格可切换暂停；减少动态效果偏好会使 CSS 动画基本停止。 | 增加滚动背景，但没有暂停控件；减少动态效果偏好仅减慢部分运动。树木图层在部分周期内未覆盖画面右侧。 |

公开预览保留这些缺点。它适合观察具体实现取舍，不足以证明某个模型普遍更强。

## 来源与证据范围

保留的报告记录了以下工具与模型标签：

| 一侧 | 工具 | 记录中的模型 |
| --- | --- | --- |
| 历史 | Codex | `gpt-6-astra` |
| 候选 | Claude Code | `deepseek/deepseek-v4.1-flash` |

- Comparison 报告于 **2026-10-19** 重新生成，沿用 **2026-10-16** 已有候选成果。本次公开整理没有重跑 Recovery 或候选执行。
- 报告生成版本为 Reprise 提交 [`c29992e`](https://github.com/caulif/Reprise/commit/c29992e7895b6d31f5bd6241c5819282acae6933)，报告格式 **6**。本页是整理后的案例，不代表后续所有版本的输出。
- 历史交付清单将 HTML 标记为 **final、reconstructed_from_history**，来源是记录中的文件编辑；它不是重新取回的原文件系统文件，也不是人工选择的替代参考品。
- 候选 HTML 来自保留的执行快照。公开副本保留恢复文件与快照的原始字节；截图使用相同的 640 × 380 iframe 视口，各交付保留自己的响应式布局。
- 原先的空 Recovery 基线已不可用，现存材料不能证明历史环境可完整端到端复现。
- 报告将耗时标记为 **不可比较**（`timingComparable=false`），相同任务范围未被证实。因此不作速度排名或节省费用的宣传；估算用量不等于已核对的供应商账单。

原报告提出了车轮、踩踏、背景和控制差异。本次整理检查源码机制，在约 3.6 秒内采样 24 个动画状态，验证暂停/恢复及减少动态效果行为，并检查桌面和窄屏预览。短片与采样不能证明所有周期、浏览器或设备上的持续流畅。本次公开预览没有调用模型。
