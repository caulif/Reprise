# 决策：面向判断的 Comparison 报告展示

状态：accepted

日期：2026-10-19

## 问题

format 6 强制提交 boundary 并固定展示“采用前注意”，替代历史材料还会在身份卡显示来源与归因说明。字段、工具和提示词共同诱导 Agent 填充注意事项，即使与配对差异重复。只隐藏标题或 CSS 不能消除这个诱因；保存内部事实也不等于读者需要看到事实清单。

## 决定

新 autonomous 请求使用 contract 6 / report format 7。取消 boundary 提交参数、模型字段及其固定栏目；Host 不再在历史身份卡插入替代材料说明。报告只展示帮助读者判断两份成果差异、价值与选择的内容，不新增等价的免责声明栏目。Agent 只把确实改变判断的条件或未知精简写入 reason 或对应配对结果／impact，表达一次，不把旧注意事项清单搬到正文。

材料身份、替代关系、证据与验证状态继续保存在内部事实和审计记录，用于准确判断；不因此把替代材料的差异归因于历史模型，也不把未知、自报或结构检查写成验证通过。双侧结果评判、Host 指标、图片及来源引用校验、作者总预算、隐私和预览绑定保持原契约。不增加模型步骤、流程或依赖。

format 1–6 与 contract 1–5 继续按各自原规则读取和恢复，旧 format 6 的 boundary 与替代说明继续可恢复；不原地修改已发布模型或 HTML，不从旧文本推导新内容。format 7 不接受 boundary，contract 6 必须绑定 format 7，旧 contract 5 不能借新格式丢失原有内容。

format 7 的会话身份卡以“历史／当前 · Agent 名称、模型、日期”区分产品与模型。名称由历史 source.productId 和当前 Candidate productId 对应的注册 Pack manifest.displayName 提供，未知 Pack 回退显示其产品 ID，不从模型名猜 Agent。可选 sessionAgents 随事实输入与报告模型保存；重建优先使用报告内冻结名称，缺字段的旧报告不补注当前注册名称。字段不限制产品枚举，后续 Pack 可复用其 displayName，无需修改模板或 Runtime 端口。

## 备选方案

**只隐藏栏目或允许 boundary 为空**：字段与提示词仍诱导填充，而且隐藏旧内容会改变历史报告恢复语义，因此不采用。

**把注意事项整体搬进理由或新栏目**：保留了相同干扰，只换位置，因此不采用。

## 影响

工具、持久化格式、HTML 槽位与请求绑定同步升级；兼容分支仅服务旧格式恢复。内部事实不丢失，新展示不再预设来源说明与采用条件清单。

## 验证

覆盖中英文新格式渲染、HTML 提取、schema 与模型重建往返，旧 format 6 原内容恢复；反向用例覆盖已删除字段、缺少理由、旧稿件字段、槽位与版本错配，并沿用隐私、篇幅、配对结果和图片校验。正式 publication 回归验证内部替代事实仍在、新展示不含固定说明、只读恢复不改写事件，以及当前草稿与预览绑定。浏览器检查桌面与窄屏布局；运行 npm run check。所有本地 fixture 验证均不代表真实模型判断质量。
