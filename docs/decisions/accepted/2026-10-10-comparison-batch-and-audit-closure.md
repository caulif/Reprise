# 决策：Comparison 在完整工具批次保存，在最小工具面完成核稿

状态：accepted

## 问题

真实对照中，保存计数在同一批工具中途达到阈值，后续已请求的渲染被拒绝，模型将临时保存边界误记为渲染不可用。最终核稿携带调查和完整发现工具的 schema，改稿后继续自动生成及压缩，消耗局部核稿窗口；图片已送达仍不能保证视觉判断和报告质量。

## 决定

保存阈值在完整 Provider turn 后触发让出，已请求批次内的剩余来源工具继续执行。重新进入来源阶段时若仍欠保存，则执行守卫阻止来源副作用及完成回调；反馈明确临时暂停、尚未执行以及先保存再恢复。整体硬保护、取消及实际阶段截止继续生效，不保证无限批次执行完毕，不重置时间预算。

严格三会话发现闭合及核稿有 delta 和已有 snapshot 时只暴露 delta 更新；缺失 snapshot 的发现收尾仍可完整初存，调查及来源保留完整更新兼容并提示优先 delta。核稿只保留读取、引文、图片观察、草稿提交、全文检查与发现更新。实际接受改稿的完整 turn 可让出 audit_revision_saved，随后 Host 调用仅有全文检查工具的 final-inspection；与 audit 共用原绝对截止，不因换 invocation 扩大预算。拒绝、超时、输出截断不制造接受事实。当前全文仍须进入下一真实 generation 才能执行 matching preview，发布契约不变。

真实复测还发现调查已完成渲染但中途保存被剩余调查时间截断，作者只能收到初存空 findings。调查 source-save 因此共享累计最多90秒的实际保存额度，来源检查间隔不消耗保存额度，每次保存及同批重试仍有绝对截止；所有保存受整体截止减390秒保护余量约束，已消耗额度不因再次保存而恢复。该窗口只允许保存已收到观察，返回调查仍使用原调查绝对截止，不增加来源检查时间或整体600秒上限。作者与后续阶段仍按原保护余量收敛，不将保存成功当作语义认证。

Pi 按本次实际暴露的工具 schema 计算上下文固定开销，恢复较宽工具面时重新计算。不能因会话曾注册大工具而提前压缩窄步骤，也不能省略当前实际曝光工具的预算。

同配置真实图像诊断能识别文字、场景和辐条越界；完整来源保存仍多次用满90秒而没有工具提交。严格路径的初存、来源保存、发现闭合、全文交付及预览因此请求 reasoningEffortCeiling=low，调查、作者及最终核稿保持原配置。Host 先将请求上限记录在 invocation-start 事件并传递给 Provider；Pi 仅降低较高档位，不提高 minimal，调用结算后恢复原档位，压缩与恢复也使用本次档位。该上限不是语义认证或精确耗时保证，上游仍可能忽略推理档位。旧请求省略该字段时行为不变；记录新增可选控制字段，模型输入正文与实际工具仍沿原回放链持久化。

紧凑 decision 输入允许最多四个注册媒体短引用及纯文本 caption，Host 生成现有媒体组件，继续走引用、路径、hash、草稿绑定与预览发布检查，caption 计入原正文长度预算。无媒体的旧 decision 不变；规范化持久化仍为原完整草稿，不新增磁盘格式。作者获得的是待审假设，caption 不伪造本会话视觉观察认证；独立 reviewer 必须按任务查图和核稿，媒体展示本身不认证画面理解。

## 备选方案

**扩大超时或更换模型。** 不解决中途拦截和无关工具预算，先修协议与工具面，不修改默认模型或资源上限。

**提交接受后直接发布。** 会跳过实际全文交付及后续模型输入，不采用。

**要求每份报告固定截图。** 非视觉任务不需要图片；按任务成功标准选证据，不采用。

## 影响

模型工具 schema、阶段让出理由、提示词及 decision 输入契约更新；事件沿用真实 invocation、工具和生成输入审计，final-inspection 作为实际 pass 记录。视觉调查优先实际输出缺陷，再解释有影响的实现机制；静态采样不得认证全部动画状态。

## 验证

反向回归覆盖超过六次检查的同批来源执行、欠保存重入拦截、拒绝改稿不能让出、最终检查共享截止、累计保存额度、当前曝光预算、注册媒体及长度/转义/失效保护。生产 Pi 回归检查实际推理选项、minimal不被提高、失败后恢复配置、控制事件及非法上限拒绝；端到端覆盖改稿后 Host 强制全文检查、后续 generation 及预览发布。真实任务另检验关键差异、画面缺陷与报告精炼程度，不将机械通过当成语义验收。

### 保存参数的可用性

专用 delta 工具允许省略重复的 kind 字段，由 Host 按端点补为 delta 后仍用原 schema 校验。通用兼容工具保持原判别字段要求；版本、digest、catalogRevision、显式保留/替换和对象完整性均不放宽。范围文字是数据，允许字面 HTML 标签名；保持非空单行、长度及数量上限，报告投影继续转义全部文字，不能将这些数据作为可执行 HTML。回归覆盖省略判别字段的实际保存、错误类型/未知字段拒绝、过期绑定拒绝及标签文字转义。

中途保存提示要求每次最多保存一个新增或修正的关键差异，每侧合并为一条短观察；其余实际观察保留在审计会话中供下一检查点或最终闭合，不静默裁剪已有 findings 或问题历史。最终闭合仍保存全部影响判断的必要修正，避免为同一侧不同检查方法生成第三条 observation。

Pi 通过公开 prepareArguments 钩子复用 SDK 参数校验与兼容转换，保留字段路径及原因，去掉 SDK 自动附带的整份 Received arguments 回显；后续 SDK 校验、执行守卫和真实拒绝审计继续生效，未知工具与非校验故障不隐藏。原模型请求/生成输入仍记录实际参数，压缩和回放不凭空补语义。原生回归验证修正后继续执行、重复调用计数和审计失败终止，检查下一真实 generation 收到短错误且不重复大参数。

视觉判断将主体识别与动作所必需的交互关系分开提问。关键接触、对齐或包含关系优先使用已有 render_artifact.geometryQueries 观察实际渲染元素；未测则该精确关系未确认，不能用同步周期、代码注释、理想目标复算或条件性措辞冒充正面优势。其它任务按自身结果选择证据，不强制截图或几何测量。该策略不认证模型会遵循或解释正确，真实任务需另验语义。

### 中途单条保存

真实任务在专用 delta 中途保存仍反复耗尽90秒无提交：仅保存一条观察也携带所有 finding/question 的显式决策和替换 schema。source-save 优先只暴露 save_comparison_checkpoint，输入为当前 binding、最多一个完整 finding 及可选 finals；Host 在同一串行队列按原 delta 校验绑定、引用所有权、字段长度和完整持久化记录。既有 finding ID 仅替换该项，新 ID 追加，其余 findings、criteria、limitations 和全部问题逐字保留。参数未知字段拒绝，不能通过此工具修改或隐式解决问题。缺少新工具的旧调用方保持原 delta 路径。

该接受只确认中途保存，不能满足独立来源复审的实际显式更新；新工具也不在来源、审查闭合、作者或核稿阶段开放。保存后继续同一来源会话，最终审查仍用完整显式 delta 决策并保留未知项。时限和总预算不增加。回归验证过期绑定、跨侧引用、未知字段拒绝，非目标对象不变，以及 source-save 与独立闭合工具面和接受事实分离。

图片读取需要3MiB而文本仍限256KiB；共享参数schema的较大上限不代表文本额度扩大。运行时对超限文本maxBytes返回可修正的invalid_read_range，不读文件，不作为致命工具失败；描述明确分模式上限与分页。取消、审计、完整性及其它真实错误仍终止。回归覆盖实际instrumentTools路径下超限反馈后成功读取及原图片预算。
