# 决策：差异优先的配对报告契约

状态：accepted

日期：2026-10-17

## 问题

format 5 同时呈现自由证据正文与短差异列表，读者仍须自行归纳两侧结果、证据强度和用户影响。推荐标题携带修复前提时偏长；Token 单位在行名中、缺价和计时限制在长脚注中，扫描时容易脱离数值。

## 决定

新 autonomous 请求使用 contract 5 / report format 6。Agent 分别提交抽象任务名、精确短推荐、一句理由、采用条件及零至三条 `pairedDifferences`：短问题 `dimension`、历史结果 `baseline`、当前结果 `candidate`、用户影响 `impact`，可附已登记 `evidenceRefs`。Host 对齐渲染；没有足够证据时允许“暂不能推荐”，未知、自报、未测试不得机械转成成功或失败。结构门仅校验形状和篇幅，不认证语义。

scratch 媒体片段仅承担完整图片及近旁图注，不再容纳重复证据表或差异正文。继续校验安全 HTML、登记引用和隐私，原图由 Host 提供可键盘访问的放大链接。坐标叠加暂不实施；单帧不证明动作连续性。必要限制在对应推荐、配对结果或媒体附近可见，不恢复折叠依据区。

每条差异可独立附 `baselineAssessment` / `candidateAssessment`：better、worse、similar、unknown、unverified。Host 仅给结果短语应用深绿、暗橙或中性灰，不追加可见状态词；朗读状态由无障碍标签提供，不给模型卡或整卡染色，不从推荐侧或自然语言猜测状态。颜色是作者的比较判断，不认证事实；缺少证据、自报和未测试不能仅因此标成更差。字段为可选的增量扩展，缺字段的旧 format 6 保持未分级中性显示，不自动补评判；新请求提示显式提供双侧状态。状态参与 schema、模型持久化及正文/预览绑定，不开放任意 CSS。

沿用900个非空白码点的作者总预算和32个码点抽象任务名预算；不为结果字段再加机械字数上限。Token 数值带小写 k 和一位小数，零与极小正值分别显示；模型费用行注明估算 USD，缺价就在单元格说明。指标表只显示三行名称与对应数值，不放小字、行内说明或脚注。计时比较状态、原因、覆盖与初始化尾巴仍保留在事实中；不能强行计算快慢百分比。

`reason` 和配对字段持久化进 report model，并经过草稿提取、Host 重建、预览绑定和最终发布。旧 contract 1–4 / format 1–5 保持原恢复语义，不原地重写已发布模型，不从旧自由字符串推导新字段。

## 备选方案

**仅调整 CSS**：保留自由证据正文与短差异列表，无法保证两侧结果对齐，也无法从结构上避免重复。未采用。

**自动解析旧差异句子**：无法可靠区分历史结果、当前结果和用户后果，会给旧报告添加未经确认的解释。未采用。

## 影响

新增 schema、工具字段、持久化报告格式和请求契约版本；Host 模板负责结构，Agent 仍负责判断的证据边界。旧报告按版本恢复。正文更便于扫描，但结构接受仍不保证内容准确，也不替代真实视觉验收。

## 验证

报告测试含完整字段往返、短推荐及最多三条的反向用例、缺字段、重复表格、隐私、原篇幅上限、缺价及零/极小值/未知；生产 publication 测试保持当前草稿与预览绑定，既有 format 5 回归测试继续通过。视觉样例采用生产渲染器，离线样例与正式模型重跑明确区分。
