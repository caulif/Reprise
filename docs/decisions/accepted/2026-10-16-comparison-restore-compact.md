# 决策：恢复 Comparison 推荐优先布局

状态：accepted

## 问题

分享优先报告将模型缩为一行、取消短差异并切换 k/M，偏离已确认的紧凑设计。字数和正式发布成功不能证明视觉与判断质量。

## 决定

新自主报告使用 format 5、autonomous contract 4，复用 format 3 的布局：突出历史/当前模型与日期、行动推荐、必要边界、核心证据、最多三条差异、耗时/Token/费用表。Token 固定 k，保持零与未知区别。作者推荐80、单条差异60、正文900个非空白码点；上限不是目标，不重复结论和证据。

保留分享能力中的抽象任务标题和明显标识检查，标题最多32；不将原始任务注入页头或标题，差异文本也参与隐私校验。保留替代材料的 Host 说明。完整视口优先，不为降低高度裁去主体；必要的隐私裁剪须说明限制，不能安全表达时省略。模型选择和图像语义仍需实际验收，不宣称规则自动判断正确性或像素隐私。

新格式补齐边界与差异中的历史/当前称呼修正；旧格式保留既有重建行为。已有报告1–4及契约1–3继续按原版本读取和恢复，不覆写历史产物；新契约不能降级为旧布局。回滚程序必须保留读取 format 5 的能力。

## 备选方案

**直接撤销分享报告。** 会同时丢失隐私能力，并影响已经发布的 format 4；直接修改 format 3 的恢复规则会改变历史报告。因此增加版本，复用已有紧凑渲染函数。

## 影响

新生成报告恢复紧凑布局，已发布文件保持不变。恢复读取须支持新增格式；发布成功与设计质量验收分别记录。

## 验证

离线覆盖正式提交、发布、恢复、三条差异及超限拒绝、固定 k、日期、替代材料、抽象任务、隐私反例与契约降级拒绝。旧 format 4 的结构与单位测试保留。真实模型报告的推荐质量和选图需另行运行验收，离线示例不能代替。
