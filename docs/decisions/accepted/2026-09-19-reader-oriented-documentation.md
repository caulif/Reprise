# 决策：按读者任务组织文档并保留历史追溯

状态：accepted

## 问题

当前说明、目标计划与历次 ADR 重复表达同一主题，部分旧规则与实现冲突。冷热目录和篇数上限没有解决读者需要拼接历史才能理解现状的问题。

## 决定

当前阅读面集中在使用指南、四篇架构、开发指南和路线图，由 README 导航。支持渠道归根 README，维护职责与可选任务简报归 CONTRIBUTING；安全政策、行为准则和 CHANGELOG 保留独立入口。结构约定只维护受控目录和机器检查所需边界。

ADR 保存真实取舍，accepted 表示当时被接受，不保证全部条款仍有效；能确认的替代关系写在历史记录顶部，正文冻结。取消热集 ≤40 和“导航只能链接热集”的限制；不为凑数搬动历史。具体字段、prompt 与模板以代码或生成区为准，普通样式微调和函数拆分不默认新增 ADR。

生成文档的事件与记录区域迁到证据、执行篇；生成器转义 Markdown union 分隔符。文档门禁把支持、治理、简报和发布检查定位到合并后的文件，仍检查必要内容；同批自测逐一删除新归宿的必需内容，证明检查能失败。覆盖率、秘密扫描及其他代码门禁不放宽。

本次不改变运行时或持久化协议。重复运行、发布事务、准备留痕和配置身份缺口写入路线图，文档整理不等于这些代码问题已修复。

## 备选方案

**只搬冷 ADR。** 无法消除当前说明内部矛盾和多份事实来源。

**把全部历史合成一篇。** 体积仍大，且会丢失各次取舍的上下文；保留原文并标后继更可审查。

**保留所有旧页作为跳转页。** 会保留原来的目录噪音；本次更新全部入站链接，直接删除已合并的当前页，历史计划仍可追溯。

## 影响

[文档导航](../../README.md)、[结构约定](../../documentation-structure.md)、[贡献指南](../../CONTRIBUTING.md)、[生成器](../../../scripts/gen-docs.mjs)和[文档检查](../../../scripts/verify-docs.mjs)。局部 AGENTS、GitHub 模板及 CODEOWNERS 同步新路径。两份已有本机讨论稿保留到 Git 忽略目录，不作为公开规范。

## 验证

文档检查验证链接、锚点、目录、命名和预算；生成检查确认新位置与 schema 一致。新增反向自测覆盖合并入口缺项与 union 表格。因修改了脚本，收尾运行 npm run check；本轮不运行真实 Runtime 或付费模型。
