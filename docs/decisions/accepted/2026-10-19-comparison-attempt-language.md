# 决策：Comparison 按 attempt 固定操作者语言

状态：accepted

日期：2026-10-19

## 问题

报告框架与模型正文原本都支持中英文，但读取语言的时点不同。较早创建的 Agent 默认值、生成中再次读取设置和离线恢复的中文默认值可能产生混合语言报告。

## 决定

Comparison 默认沿用 TUI 操作者语言，每个 attempt 在开始时取一次快照。该值随开始事件与冻结 Context 保存，优先于内置 Agent 的构造默认值；模型提示词明确结论、理由、成对结果、影响和图片说明使用同一语言，与历史任务语言无关。代码、路径、模型及 Agent 标识和原文引用不翻译。

本次草稿修订、模型请求重试、报告发布与失败页面均使用该快照。语言设置的后续变化仅影响下一次 Comparison。报告模型保存可选语言字段，重建优先使用报告自身语言，避免框架翻译而正文不变。

有效配置审计同样使用本次语言。即时 Comparison 从已提交的运行配置派生独立的 attempt 配置绑定，开始事件不再把原运行引用当作本次有效配置；持久化重比在绑定配置时应用已冻结的语言，连接 probe 也引用这一绑定。相同 attempt 已有一致配置时不重复绑定；不修改原运行的 manifest、配置 artifact 或共享 Agent。无有效配置引用的自定义 Port 继续保持未记录，缺少已提交绑定的引用则拒绝执行。

离线恢复优先使用冻结 Context 的语言；旧 Context 缺字段时读取原报告 HTML 的 lang，缺少标记则保留旧中文默认。旧模型缺字段仍接受调用方原有语言参数。新增字段采用现有 schema 校验，无批量迁移，不修改已发布文件。需要其他语言版本时重新生成。

## 备选方案

**每个阶段读取当前 TUI 设置**：切换设置可能导致一次报告内语言不一致，因此不采用。

**根据历史任务推断语言**：用户已选择英文时，中文历史材料仍会迫使报告回到中文，因此不采用。

**切换界面时自动翻译旧报告**：需要重新生成正文和校验，且会改变已发布事实；不作为界面切换副作用。

## 影响

Context 与报告模型增加可选语言事实，旧格式仍可读取；内置 Agent 按本次 Context 选择语言，不再由构造时默认值主导。不会增加独立语言设置或真实模型调用。

## 验证

回归覆盖 Agent 默认中文时使用英文 attempt、同一 Agent 的后续中文 attempt、即时及持久化重比开始后切换设置、失败页面语言、模型重建忽略当前界面语言，以及有／无冻结语言的旧英文报告离线恢复和发布。使用本地 fixture，不代表真实模型必然遵守语言指令；运行 npm run check。
