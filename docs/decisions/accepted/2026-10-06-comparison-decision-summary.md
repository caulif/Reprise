# 决策：Comparison 的当前提交明确展示任务结论与决策边界

状态：accepted

## 问题

真实 Comparison 能正确调查、接受、检查和预览一个简短草稿，却仍可能把任务级判断压缩成单项技术优势。内部 findings 已记录用户影响和重要未知，最后正文可以只保留优势的测量数字，重要未知则从主文消失。删除未经支持的成功保证虽可纠正过度主张，不能说明未验证的任务关键质量已经不再影响用户选择。结构、引用、字数和当前版本绑定都不能替代语义判断。

## 决定

- 为当前 `submit_comparison_draft` 工具增加必填普通文本 `decisionSummary` 与 `decisionBoundary`。Summary 说明原任务结果、用户影响及证据支持的明确、有条件或未定取舍；Boundary 说明会改变选择的已知问题、重要未知、适用范围和剩余工作。不强制赢家、固定差异数量或过程段。
- 基础持久化/旧提交 Schema 保留这两个字段为 optional，兼容既有保存结果与旧端口；当前工具要求二者存在，Summary 非空。Boundary 可以为空，仅适用于尚未识别重要限制的提交。新提交已有 Summary 且当前 accepted findings 的 `importantLimitations` 非空时，空白 Boundary 明确拒绝，返回原模型声明供修复；它们不被认证为事实，也不要求照抄常规来源和指标清单。旧提交不据此补造边界。
- Host 转义两个普通文本字段，并作为实际比较区前置段落显示。它们连同 headline 与 comparisonHtml 一起计入现有主文字数；不能放进折叠详情绕过限额。工具 Schema 校验仍使用 `Value.Check`，新增模型可见输入沿用实际工具调用、完成正文与 generation snapshot 的事件审计，不注入伪造观察。
- `single_difference` 是一个决定性对比的压缩方式，不能用来删除另一项独立、会改变任务可用性的质量、反例或重要未知。多个独立质量影响选择时按 `multiple_differences` 摘要取舍；同一缺陷的原因、测量和后果仍不构成多个差异。先保留用户影响和决策边界，再保留必要证据，将技术推导放进可选详情。
- 独立 source pass 从任务关键质量出发检验实际输出链，不只检查作者选择的优势或成功保证。完整审查比较实际 Summary/Boundary 与任务标准、findings、userConsequence、限制及独立反证；没有显式广泛保证，也不能把重要未测分支从判断中隐去。未知可以支持有条件或未定结论并正常结束，无需无限追加测量。
- 过程仅选会影响结果、用户介入或剩余工作的实际记录；本次 Comparison 检查不得归给原模型的验证。没有重要过程差异时不制造固定段落。检查、预览、当前 generation 交付与 Recovery 绑定继续证明机械状态，不能认证判断完整、真实或已被模型理解。

## 备选方案

**只强化提示。** 不能保证任务级结论及重要边界具有可审计的实际可见位置，也不能拒绝字段遗漏。采用最小文本工具契约，同时保留通用提示与独立语义验收。

**Host 自动选择赢家或按关键字判断限制完整性。** Host 无法根据引用有效或字符串命中判断真实任务重要性；固定例子或像素阈值会把通用 Comparison 变成样例分类器。只检查声明存在、已有重要限制时边界不空、实际可见文本及绑定，明确这些都是机械保障。

**所有 criteria/限制都强制生成固定展示行。** 常规检查、已解决问题和来源信息会挤占简短摘要，还会把模型声明冒充事实。当前选择简短任务判断与边界；自然语言是否充分仍由独立审查和真实模型评估判定，不能把非空字段当成产品验收。

## 影响

扩展当前工具与报告内容契约，兼容既有持久化和旧提交。新字段作为普通文本显示，避免把模型 HTML 当成结构或隐藏关键边界。既有字数、预算、lane、effort、maxTokens、当前检查及预览门禁保持原值，不增加依赖或样例答案。

该最小契约不能保证模型发现全部反例、正确判断每个限制的重要性或写出有用正文。非空 Boundary 也可能遗漏关键问题；真实语义复核仍需核对任务、实际输出链、完整主文与详情，不能只检查字段和字符数量。继续对同一冻结输入和合成任务分别验收稳定性与可迁移性。

## 验证

自动化逆例覆盖当前工具遗漏字段、Summary 空白、已有重要限制但 Boundary 空白、转义与全主文字数计算；旧提交兼容，不补造旧边界。实际 application fixtures 保留真实 inspection checkpoint、后续 generation、最终当前检查及预览事件，新增字段不能代替原绑定。通用 compose/source/review 提示纳入快照，避免未来又把简短等同于只呈现优势。最终源码须先编译，再执行相应 focused 与 `npm run check`；门禁通过不表示真实任务语义已通过。
