# 决策：空槽位与结论优先的 Comparison 报告骨架

状态：accepted

## 问题

原正式报告的指标卡比主要结论更突出，Token 总量与明细一起折叠。初始比较区还会按媒体目录生成候选配对或无图提示；这些导航线索容易被当作已经选好的正文。填好内容的设计样稿适合确认排版，但其中的赢家、差异数量、证据内容与核验标签不应成为模板默认值。

## 决定

- Host 继续拥有报告样式、事实指标、双侧身份与证据目录；Agent 的结论、比较正文与可选详情初始留空。不可见的组件原型只给出可选结构，不提供实际判断或媒体引用。媒体目录仍可读取，具体配对由 Agent 根据任务选择。
- 突出结论区，时间、估算费用和 Token 总量紧凑并列，Token 分项按需展开。保留现有 format 2、compact 标记、区域顺序、金额与时间格式及指纹校验，不为视觉调整迁移旧报告。
- 当前自主 Session 的提示词要求按实际交付撰写差异与用户影响，必要证据和重要未知就近呈现；不用的组件省略，不固定赢家或差异数量。HTML 模板及提示词仍走现有 briefing、工具读取和模型输入审计，不新增独立模型输入来源。
- 链接保留可辨认样式与键盘焦点，配对图片按自然比例呈现；窄屏堆叠双侧证据。安全片段、媒体授权、证据来源、预览绑定及旧整页草稿修复机制不变。

## 备选方案

**只改提示词。** 要求简洁无法改变固定骨架的视觉层级。

**直接使用填好的样稿。** 会引入未经验证的内容。选择空槽位与可选组件，保留任务适应性。

## 影响

指标继续位于比较正文前，但压缩体积，避免正文增长后掩埋指标，也避免调整现有区域顺序契约。独立通用工具试验的模板不属于正式生产骨架，本次不改变其单独的交付约定。没有持久化迁移，旧报告不原地重写。

## 验证

回归覆盖空槽位、带媒体目录时不自动填充正文、总量可见且不重复、未知与零的区别、指标改写拒绝及旧指纹兼容；中英文快照随生产渲染器更新。桌面与窄屏视觉检查使用合成材料，不代表真实模型判断准确率或真实任务质量验收。无新增门禁、持久化字段或付费模型调用。
