# 决策：分享优先的精简 Comparison 报告

状态：accepted

## 问题

原紧凑报告同时显示自由正文与独立差异列表，同一判断容易被重复表达。原始任务全文和长路径进入页头，模型大卡片压过任务结论；固定 k 单位也使百万级 Token 难读。用户需要精准、简洁、便于截图分享的结果。

## 决定

新增 format 4，使用抽象任务短标题、一行历史/当前模型身份、小字号强调结论、必要边界、单一比较正文和三行指标。去掉品牌、原始任务全文、独立差异列表与预置正文表格；不强制填满差异或图片。指标按量级使用 h/m/s、k/M 和美元符号，保留未知、缓存与估算说明；口径未确认可比或记录不完整时提示，不据此排名。

新自主请求记录 contract 3 并绑定 format 4；contract 1/2 和报告 format 1/2/3 继续按原契约读取、重建及恢复，不将新的篇幅、隐私或版式规则追溯施加于旧报告。既有 Host 身份、数值指纹、证据、媒体、预览及实际 generation 绑定仍须通过。新作者文本总预算500个非空白码点，结论60、抽象标题32，不另增调查阶段。

报告中的姓名、单位、私有项目、文件名、路径及联系方式应概述为通用角色与对象；截图、图注、替代文字和引用同样遵循。Host 不将原始任务灌入 HTML 标题或页头，并拒绝作者字段中明显的路径、文件名、邮件及电话模式；拒绝返回可修正反馈。该规则不等同通用身份识别器或像素脱敏认证：Agent 必须检查必要证据，选择不泄露身份且不扭曲结论的片段；不能确认安全则省略图片，以抽象文字解释。不得篡改已登记原文引用来伪装脱敏，须选择安全原文或明确使用自己的概述。

原件、事件、私有审计和已封存媒体不被改写。报告适合截图分享的目标不意味着原件链接、实验目录或完整 HTML bundle 自动成为可公开材料；不承诺仅靠规则即可识别一切个人信息。

## 备选方案

**只改提示词或继续使用 format 3。** 无法消除 Host 自动输出的原始任务和重复布局，且直接改变旧格式会破坏历史重建契约，因此采用新格式。

**自动识别并替换一切个人信息。** 通用文本规则无法可靠判断姓名和图像身份，也可能扭曲原始证据，因此采用明显模式拦截、模型抽象概述与不确定时省略证据，不宣称完全匿名化。

## 影响

新报告按分享优先布局生成，旧报告保持原规则；事件增加明确版本约束。不会删除原件或把私有审计变成公开材料。隐私模式可能误拒绝确有必要的技术文件名，模型应改写成对象或职责，不把原文改写后冒称原始引文。

## 验证

反向用例覆盖原始任务不进入新 HTML、单正文结构、指标篡改、新契约降级、正文/标题/边界/图片标签中的明显标识、引用不豁免脱敏检查，以及超长作者字段。生产入口测试覆盖接受、预览、发布与持久化恢复；旧格式回归继续执行。没有模型调用的结构测试不认证自然语言质量或图片脱敏。
