# 决策：交付优先输入与可重放浏览器检查

状态：accepted

## 问题

单自主 Session 仍可能用完整体时间调查却不提交。此前真实复测的模型往返占约28分45秒，工具执行区间约59秒；这不能仅靠工具并行解决。工具也缺少点击、键盘和媒体偏好，导致交互检查绕路。Codex 对照试验与生产模型不同，不能据一次结果认证能力或稳定率。

## 决定

初始输入先给原任务、明确的 HTML 交付目标、剩余整体时间和双侧交付线索，随后才是完整导航及可选 Host 指标。要求读取按序用户需求，避免漏掉后续更正；线索不认证终稿，未索引不代表不存在。过程日志保留，按会影响判断的问题展开。提示鼓励在主要差异有依据后写工作稿，再检查重要声明和呈现；不增加强制阶段、调用数量上限或任务特定判题。初始及每次工具回执展示的预算与调用实际较短超时统一，共享整体截止不因续写重置。

扩展现有 render_artifact：media 在加载前设置 prefers-reduced-motion / prefers-color-scheme；actions 按序重放 click、fill、key、scroll、wait、inspect。点击/输入要求唯一、可见、可用元素；inspect 返回匹配数、文本、表单值、可见性、状态与 DOM bounds。输入 JSON 和浏览器返回观察经过 core schema。没有任意 JS 或 URL 参数。复用临时 profile、冻结 bundle 服务、网络/下载/弹窗隔离、取消与超时清理；不接触真实用户浏览器，也不开放直接浏览器 shell。

每次调用新开页面，不保留跨调用隐藏状态。要修改实验条件须重放完整动作序列。带 actions 时帧采样相对动作序列完成后的时间，inspect 观察对应其动作位置；不把两者冒充同一瞬间。请求动作、媒体条件与观察写入现有 renderedCheck 工具回执和模型输入审计；大结果经 schema 校验保存完整测量文件再分页，继承既有引用及原生图片授权。DOM 是不可信页面数据，不是任务成功证明。无这些参数时保留原加载后采样语义及旧调用兼容。

## 备选方案

**开放任意 CDP 或页面脚本。** 灵活但扩大执行与访问边界；常见交互优先通过类型化操作实现，不把整个浏览器协议交给模型。

**持久浏览器会话。** 减少重放但增加跨调用状态、清理和历史复原契约；本次采用一次调用的完整动作重放。

## 影响

采用一次调用的动作重放，避免新增浏览器会话生命周期与恢复状态机。它足以直接检查常见交互与偏好；不声称覆盖 Codex 的全部浏览器或终端能力。复杂导航、iframe、拖拽等能力需有具体需求再扩展。

## 验证

自动化覆盖动作顺序、唯一选择器拒绝、参数边界、原生图片/工具正文与预算反馈的兼容、实际较短超时，以及交付优先导航。显式本机浏览器验证点击、Enter、输入、滚动、媒体偏好和外部请求拦截。离线门禁和浏览器检查不证明模型可稳定在30分钟内写出合格报告；该结论需另外做同模型受控复测。
