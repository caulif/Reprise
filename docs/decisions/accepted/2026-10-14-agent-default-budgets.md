# 决策：默认时间预算 24 小时与上下文 256k

状态：accepted

更新[Comparison 整体时间预算](2026-10-11-comparison-total-time-budget.md)、[自主 Session](2026-10-11-comparison-autonomous-session.md)、[coding 试验](2026-10-12-comparison-coding-trial.md)与[单 prompt Recovery](2026-10-13-single-prompt-recovery.md)中的默认时长，保留各自其余契约。

## 问题

30 分钟默认截止会提前终止长任务。只提高 Agent 调用超时仍会被 Recovery 外层总截止或 Comparison 工具/试验截止中断；默认上下文 128k 也会使长证据调查更早进入压缩。

## 决定

Recovery 默认单次调用及覆盖准备、模型、校验与封存的总截止均为 24 小时。Comparison 默认整体时间为 24 小时，调用继续取实际剩余整体时间与配置调用超时的较小值；coding 试验与其 shell 命令超时也改为 24 小时。不增加阶段、请求数、工具数、累计 token 或金额额度。Controller 自身调用仍无界，显式较短预算与用户取消继续生效。

自定义 OpenAI-compatible 模型未显式配置时，上下文默认 256,000 tokens；压缩逻辑缺失有效模型窗口时采用相同值。目录模型与显式窗口保留其配置，单次最大输出默认仍为 16,384 tokens。该默认声明不是对供应商实际窗口支持的探测。

## 备选方案

**只修改 Agent 工厂。** 外层与工具截止仍然提前中断，且压缩回退与模型注册默认窗口不一致，未采用。

## 影响

新调用使用新默认值，不改写历史事件与实验 manifest。长任务可持续更久；没有新增费用上限，也不保证任务质量或供应商支持 256k。回滚默认值即可，不涉及 on-disk 迁移。

## 验证

更新工厂与自定义模型注册的既有断言；模拟时钟检查 Comparison 超过原 30 分钟仍能工作、24 小时到期拒绝继续，覆盖压缩窗口回退及显式窗口优先。运行项目门禁，不发起真实计费请求。
