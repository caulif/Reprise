# 决策：Comparison 通用 coding agent 对照入口

状态：accepted

预算状态：superseded；30 分钟默认预算已被[24 小时与 256k 默认预算](2026-10-14-agent-default-budgets.md)取代，其余决定继续有效。

## 问题

本决策仅用于显式启动的试验，不替代默认 Comparison 或既有恢复契约。

单 Session 仍要求证据短引用、登记、片段提交和正式预览绑定，难以判断这些模型侧协议是否拖累交付。一次 Codex 对照同时存在模型和工具差异，不能独立归因。

## 决定

提供 comparison-coding-trial 脚本入口，复用现有 AgentHost、Pi provider、文件/Shell、隔离渲染和PNG变换。参考[Codex工具装配](https://github.com/openai/codex/blob/8c0f7011674145da7e10627769fb221c74fbf7a0/codex-rs/core/src/tools/spec_plan.rs)按能力提供工具和自主交付的方向，不声称完整实现Codex的PTY或全部工具。

调用者显式给出独立输入bundle、全新输出目录、模型配置目录及一个任务prompt文件。输入声明为本次比较的冻结快照，文档中的历史主机路径只是元数据，不要求模型搜索当前主机重建来源。模型直接生成完整report.html，可自带样式、脚本和本地资产；没有证据catalog、Host shell、submit_report、preview_report、强制审查或结构化最终回复。文件路径渲染同时适用于来源和正在编写的报告；原生图片与裁切无需登记。

仅设整体30分钟截止，不向任务提示或工具回执追加剩余时间提醒。任务目标及交付形式由调用者prompt提供，系统提示仅说明来源与工具环境。任务耗时、token及费用作为独立来源数据提供；费用注明价格快照估算口径，缺失保持未知，不要求模型编造。保留模型输入/工具/图片审计、现有凭据脱敏与环境清理、文件工具只读source挂载和隔离浏览器。Shell沿用已有进程工具和命令检查，直接浏览器启动及全局进程终止命令前置拒绝；不宣称命令检查能防止脚本间接绕过，也不宣称操作系统沙箱。输入必须是专用副本，试验前后校验内容hash，不挂载生产工作区或凭据。输入变化不计成功。

真实调用必须REPRISE_REAL_MODEL=1。输出目录独立且不得覆盖已有目录，审计位于模型文件工具工作根之外。实验的completed只表示模型正常结束、完整HTML存在且输入未变，不认证语义或页面质量，不进入正式Comparison发布及恢复流程。

提供可选的[报告骨架](../../../scripts/comparison-report-template.html)与[通用提示词](../../../scripts/comparison-report-prompt.txt)，固定总体判断、关键差异、运行指标三个信息区域，省去模型重复设计页面结构的开销。证据形式随任务选择，不固定截图或判题；不新增补充详情、检查记录或方法附录。计量默认只呈现紧凑时长、总token和估算费用，精确值可放title，缺失保持未知。调用者将模板作为冻结输入显式提供，模板和prompt仍通过既有审计复原，不由Host隐式注入，不增加模型请求配额或强制分阶段流程。模板只约束表达，不认证结论准确性。

## 备选方案

**直接替换默认入口。** 删改默认生产发布协议会同时改变历史报告与恢复承诺，并使质量归因更困难。先用同模型、同冻结交付物的独立试验验证，再决定是否把简化方向迁移为默认入口。

## 影响

模型可以自由设计报告，减少平台协议操作，但也不再受HTML fragment安全子集限制。报告作为本地试验产物，原始不可信页面仍通过隔离renderer检查。试验不自动发布、提交或推送，不新增依赖。

## 验证

测试覆盖直接写完整报告、来源只读、路径逃逸及junction拒绝、来源/报告共享动作渲染、原生图片交付和裁切边界。代码构建后执行项目check。真实试验另记录耗时、调用、输入hash和成品视觉检查；一次成功不代表通用稳定性。
