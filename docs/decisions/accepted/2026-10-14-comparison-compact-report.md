# 决策：Comparison 推荐优先的紧凑报告

状态：accepted

## 问题

自主 Comparison 能调查完整材料，但报告可持续增加正文、详情与指标解释，读者难以快速确定采用什么、有什么影响。局部裁剪可能被当作完整交付；历史耗时仅配对开始/结束事件，漏读完成事件中的 duration_ms，且与候选整体区间混用。

## 决定

保留单个自主 Session 和任务适配的证据选择。新报告使用 formatVersion=3：历史/当前实际模型、推荐与必要边界、核心证据、最多三条差异、三行指标表，分析模型置于页尾。推荐最多80个非空白 Unicode 码点，每条差异最多60，全部作者正文最多900，含边界、表格、图注和代码。上限不是目标；重要未知必须保留，证据不足可推荐核验。Host 校验结构与长度，不认证推荐的语义正确性。

双侧模型名下方保留 Host 冻结的 UTC 会话日期，作为次要背景信息；未知不补齐。日期来源、兼容和审计规则由[双侧会话日期](2026-10-14-comparison-session-dates.md)拥有，不随模板切换丢失。

submit_report 提交推荐、boundary、differences 与 scratch 内证据片段，不接新格式的 detailsPath。新自主提交契约独立标记为版本2；旧版本1和报告1/2按原规则恢复，不静默重解释或重写。片段、字段与指标经 schema 和既有来源检查，接受、预览、发布及恢复绑定同一内容和 catalog。改稿必须重新预览，实际预览回执进入同 Session 后续模型输入且正常完成后才能发布。

耗时、Token和估算费用由 Host 冻结事实投影。Token表头统一k（1000），数值一位小数；正数舍入为零显示“<0.1”，未知与真实零分开。计费和原始计数不变。计时按可验证轮次去重、逐轮选择有效duration或匹配边界，并保留覆盖、来源与诊断；候选整体区间和轮次累计不混写。相同单位不证明边界相同，不能证明可比时只作简短提示，不推断速度优势。

截图先展示完整原始视口、保持比例；裁剪只作补充且保留来源。完整视口不等于完整长页，长页优先用现有受控滚动多帧检查并披露条件，不新增无界全页截取。预览回传实际布局和加载信息，不能用隐藏内容、裁图或极小字号满足篇幅。移除读者侧依据/完整ID/指标口径展开区，内部审计和完整事实仍保存。

每帧的滚动位置与文档高度取自紧随该帧截图的布局观测，不使用整批末尾布局回填早期帧。截图和布局观测不是原子快照；缺少逐帧观测时省略该帧布局元数据，批次反馈仍明确表示最后一帧后的观测。

截图去重身份包括捕获范围、滚动坐标和文档高度；字段缺失不等同于零。像素相同但覆盖事实不同的截图分配不同媒体引用，同一覆盖事实的登记重试复用已有引用，不因重试时间变化生成新记录。

用户指定替代基准由 Host 在冻结 reportFacts.replay 中保存可选 baselineIsSubstitute 标记，随请求和恢复沿用现有 schema 与审计链路。格式3在模型信息下固定展示“材料为替代品、模型与指标属于原会话”的本地化短说明；该说明属于受保护的 Host 页头，不占作者正文预算，不依赖模型主动披露。旧 facts 无标记时不推断替代身份，恢复不读取后来的基准选择。

## 备选方案

**只缩短提示词。** 无法保证篇幅，也不修复计时、发布或恢复。继续叠加 reviewer/阶段不解决阅读问题。完全自由HTML会绕过Host事实和安全边界，因此继续复用安全片段与正式渲染链路。

## 影响

工具提交、HTML结构和持久化模型需要同步版本化；旧格式校验不放松。模型须对超长稿件修订，不能将长文移入折叠块。数值恢复不等于跨产品计时完全同义。静态帧、自动化通过和正常发布均不证明任务判断、全程动画或真实模型质量通过。

## 验证

自动化覆盖0–3条与4条拒绝、推荐/差异/整体超限及隐藏文本反例、k与未知值、模型归属、缺start的duration恢复、重复和部分轮次、候选配对，以及新格式提交到预览绑定、发布和恢复与旧格式兼容。使用正式shell检查桌面与窄屏。真实四任务的自主报告质量须另行授权调用，并记录attempt、实际模型和报告；样稿和离线fixture不能代替真实验收。
