# 决策：Comparison 按注册引用观察图片

状态：accepted

## 问题

图片读取曾沿用文本分页的 64 KiB 默认上限，正常截图会被拒绝；普通图片参数错误又经工具异常升级为整个 invocation 失败。仅声明模型支持图片不能解决交付故障。

## 决定

选择性借鉴 Codex 的独立图片工具与可恢复输入反馈，保留 Reprise 的证据所有权、阶段和事件边界。Comparison 新增 `view_image({ref})`，只解析当前 catalog 的注册媒体短引用或完整引用，不接受任意路径；首版交付 PNG，其它来源通过 `render_artifact` 生成 PNG。复用既有授权、hash、真实路径、像素和附件交付检查，不增加依赖或隐式缩放。

旧 `read(format=image)` 保留路径和 MIME 参数，图片默认及最大预算为 3 MiB，PNG 校验头部和像素上限；文本默认 64 KiB、最大 256 KiB 不变。图片不分页、不截断。授权拒绝、图片偏移/大小、MIME 与 PNG 头部/像素错误返回正常工具结果和后续建议；取消、审计失败、注册图片 hash/路径完整性失败仍抛出，不修改全局 Provider 异常语义。PNG 头部检查不等于完整解码认证。

`view_image` 属于有效来源检查，在调查、独立来源复审、补查及审计阶段可用；纯理解、保存、作者和预览步骤不扩展工具面。实际调查与复审提示词共享简短图片指导，按任务需要选证据，动画对照相同条件下的相关状态。只有实际请求的图片 manifest 能证明送达；图片工具成功不认证模型理解或结论。

## 备选方案

**全盘移植 Codex 工具及任意路径读取。** 会绕过既有 catalog、证据归属和阶段约束，不采用。

**只提高文本限制或扩大模型预算。** 仍混淆分页与图片，不解决工具异常和使用入口。

**全局吞掉工具异常。** 会隐藏审计与完整性故障，不采用。

## 影响

无 on-disk 格式、Runtime 端口或默认真实调用策略变化。旧报告与引用保持可读；工具 schema 与角色提示词发生变化，更新快照。模型不支持图片时 Host 继续移除原生图片并返回 unsupported_model。该批不改变报告媒体格式、模型选择或阶段预算。

## 验证

回归覆盖大于 64 KiB 的图片、文本分页、可修正错误后继续执行、授权拒绝、PNG 头部与预算、注册 hash、取消、文本模型及阶段暴露/强制执行。既有原生附件审计、请求重建、History 回放测试继续验证完整交付链。真实 Comparison 重跑用于观察模型实际行为，不由 fixture 代替视觉语义验收。
