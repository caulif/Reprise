# 决策：单人到开源的轻量文档与贡献流程

状态：accepted

## 问题

单人维护需要保留取舍而非增加仪式；外部贡献者需要能找到当前事实和审查入口。完成计划、根目录一次性材料及导航中的 ADR 长列表混杂，会使历史目标被误认成当前实现。

## 决定

沿用[建立决策记录](./2026-08-14-establish-decision-records.md)的唯一因果层。测试证明当前行为，ADR 保存真实弃案；[触发与豁免](../README.md)限定需要记录的契约变化，小修不写流水账。

默认单人流程按改动面验证、更新事实；外部 PR 或第二维护者参与时使用 PR 勾选和[治理](../../GOVERNANCE.md)审查边界。事实导航与决策检索分开，开发命令集中于[开发指南](../../development.md)，cookbook 只提供少量操作入口。目录旁 AGENTS 只索引现有模块规则。

[文档结构](../../documentation-structure.md)定义生命周期：结束的计划与一次性材料退出受控区，开放计划保留未关闭原因，MASTER 只留短证据。计划模板是可复用入口，不是未完成项目。尚缺的真终端、付费模型和 Runtime 验证保持开放；文档清理不能替代产品验收。

## 备选方案

**全面采用 DSH / Cordis 与 Agent Notes。** 产品架构不属于文档整理范围；平行 notes、双语三件套及归档 hash 增加第二套因果层和维护成本，拒绝引入。

**每次修改写 ADR、维护全局 INDEX、一次性拆分全部 ADR。** 小修和库存整理不值得承担这类仪式；用搜索找相关弃案，只有触及双写契约时才局部整理。

**保留所有已结束计划与根目录草图。** 会让公开导航依赖历史库存；Git 保存历史，本机副本可保留，但受控文档不能依赖它。

## 影响

贡献入口、PR 模板和所有权说明可发现；默认路径保持轻量。运行时、三 Agent Host、门禁脚本与阈值均不变化，不创建全局 ADR 索引。本次只落地文档与协作边界，后续规则加码须另行评估。

## 验证

`npm run verify:docs` 检查链接、目录模型、ADR 格式及既有字符预算。PR 提供实际退出码与自检输出；审查确认根目录一次性材料退出跟踪、导航没有 ADR 墙、开放证据未被宣布完成、默认 smoke 仍需显式 opt-in。机械门禁不代替语义审查。
