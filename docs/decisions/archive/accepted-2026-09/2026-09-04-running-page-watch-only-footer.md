# 决策：运行页只读观看，页脚只保留有效键

状态：accepted
日期：2026-09-04

## 问题

候选运行页页脚列出选择、过滤、展开、全文、切栏、查找和回到最新，并画一条看起来能输入的 `>` 提示。运行面是双栏 `ScrollView`，展开标志不参与绘制，多数键没有可见效果。用户会以为整行快捷键都坏了。

## 决定

运行页（含恢复）是只读观看面。页脚只保留 `Ctrl+C` 取消和 `?` 按键说明，不画伪输入行。结果页页脚不列查找。全文 overlay 只保留 `Esc`。错误页 `Esc` 与 Enter/`b` 一样返回。页脚清单以 [`docs/product/tui.md`](../../product/tui.md#10-页脚快捷键) 为准，只写该页会响应且有效果的键。

## 备选方案

**修好双栏选择与展开，保留原页脚。** 运行中不需要这些操作，修布局成本高。

**页脚留空。** 取消是这一页唯一必须暴露的操作。

## 影响

查找、过滤、切栏等处理函数可以仍在运行页响应，但不出现在页脚。结果页 `/` 不再进入画布查找。

## 验证

`test/widgets.test.ts`：运行 hints 含 `Ctrl+C`、不含 `[f]`/`[o]`/Enter；`helpLines('running')` 不含 Find/Expand/filter。`test/page-input.test.ts`：错误页 Esc 为 `return`。反向：运行页脚再列出 `[f]` 或伪输入行则红。
